# Homebrew tap for Battle Balut

A [Homebrew](https://brew.sh) tap for [Battle Balut](https://battlebalut.com) —
the Danish dice game Balut, played asynchronously against other players.

## Install

```sh
brew install --cask utopleman/battle-balut/battle-balut
```

Needs an Apple silicon Mac on macOS 14 Sonoma or later.

## Upgrade

```sh
brew upgrade --cask battle-balut
```

`Casks/battle-balut.rb` is written by the macOS workflow in
[UtopleMan/battle-balut](https://github.com/UtopleMan/battle-balut) on every build of `main`; don't edit it by hand.
